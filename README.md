## Resmi amac

Turkiye sinirlari icinde (ve balkonlarda) yasayan kedilerin yasama faaliyetlerini seffaf, olculebilir ve biraz da sacma hale getirmek.

Bu yazilim:
- gercekten calisir
- gercekten oy kullanir
- gercekten hicbir seyi cozmez

## Kurulum

```bash
python3 meclis.py
```

Bagimlilik yoktur. Kediler zaten kendi kendilerine yeter.

## Nasil calisir

1. Meclis acilir.
2. Rastgele bir yasa gundeme gelir.
3. Yedi kedi oy kullanir (veya uyur).
4. Sonuc basilır.
5. Tarih yazilir, herkes dagilir.
